# Client Photo Gallery

Production-grade web gallery for delivering professional photo work to clients — built from scratch using Firebase Hosting, Cloudinary CDN, and Google Drive integration.

## 🚀 Live Demo

🔗 https://iryna-kaida-gallery-elf.web.app

## 🎯 Why I built this

Real-world need from my 10+ years as a photographer — clients need a clean, fast way to access and download high-resolution photo sets. Existing solutions felt clunky or expensive. Built my own.

## 🛠 Tech Stack

- Frontend: HTML5, CSS3, JavaScript (ES6+)
- Hosting: Firebase Hosting
- CDN: Cloudinary (image delivery + transformations)
- Storage: Google Drive integration
- Auth: Firebase Authentication

## 📚 What I learned

- Integrating multiple third-party services (Firebase + Cloudinary + Google Drive APIs)
- Real production deployment pipeline
- Image optimization for fast load times
- Client-side state management for gallery navigation

## 🏃 Run locally

```bash
git clone https://github.com/kaida-iryna/client-photo-gallery.git
cd client-photo-gallery
# Configure Firebase + Cloudinary credentials in config
# Open index.html in browser or serve with Firebase CLI
```
